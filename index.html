الخطوة 2: تنظيم الملفات

📂 هيكل المشروع

تنظيم الملفات من أهم الحاجات اللي بتفرق بين المحترف والمبتدئ:

📁 my-portfolio/ ├── 📄 index.html ← الصفحة الرئيسية ├── 📁 css/ │ ├── 📄 style.css ← الملف الرئيسي │ └── 📄 responsive.css ← Media Queries (اختياري) ├── 📁 images/ │ ├── 🖼️ profile.jpg ← الصورة الشخصية │ ├── 🖼️ project1.jpg │ ├── 🖼️ project2.jpg │ └── 🖼️ favicon.png ← أيقونة الموقع ├── 📁 fonts/ ← لو حملنا خطوط (اختياري) └── 📄 README.md ← وصف المشروع

⚠️ قواعد تنظيم الملفات

• أسماء الملفات lowercase + dash (مش underscore أو مسافات).

• الصفحة الرئيسية لازم اسمها index.html.

• حط كل الصور في مجلد images/.

• حط كل CSS في مجلد css/.

• استخدم صور مضغوطة (TinyPNG) عشان الموقع يبقى سريع.

Step 2: CSS Variables

🎨 نظام الألوان والقيم

هنبدأ بـ CSS Variables في :root — ده هيسهل علينا تغيير أي قيمة في كل الموقع من مكان واحد.

css/style.css — Variables + Reset 
/* ===== CSS Variables ===== */
:root {
    /* Colors */
    --primary: #4A7C59;
    --primary-dark: #2D5F3F;
    --primary-light: #7BA889;
    --secondary: #D4A574;
    --accent: #B8860B;
    
    /* Neutrals */
    --bg-main: #FAF7F2;
    --bg-card: #FFFFFF;
    --text-dark: #2C1810;
    --text-body: #4A3728;
    --text-muted: #6B5744;
    
    /* Typography */
    --font-family: 'Cairo', sans-serif;
    --font-size-base: 1rem;
    --line-height: 1.6;
    
    /* Spacing */
    --spacing-xs: 0.5rem;
    --spacing-sm: 1rem;
    --spacing-md: 2rem;
    --spacing-lg: 4rem;
    
    /* Borders */
    --radius-sm: 8px;
    --radius-md: 12px;
    --radius-lg: 24px;
    
    /* Shadows */
    --shadow-sm: 0 2px 8px rgba(0,0,0,0.08);
    --shadow-md: 0 8px 20px rgba(0,0,0,0.12);
    --shadow-lg: 0 15px 40px rgba(0,0,0,0.15);
    
    /* Transitions */
    --transition: all 0.3s ease;
}

/* ===== Reset ===== */
* {

Step 10: Responsive Touches

📱 Media Queries للموبايل

رغم إننا استخدمنا Mobile-first + auto-fit + clamp()، لسه في حاجات صغيرة محتاجة media queries:

CSS — Responsive Adjustments 
/* ===== Mobile Navigation ===== */
@media (max-width: 768px) {
    .nav-links {
        display: none; /* مخفي على الموبايل */
    }
    
    /* ممكن نضيف hamburger menu بـ JS */
}

/* ===== Tablet Adjustments ===== */
@media (min-width: 768px) {
    .container {
        padding: 0 2rem;
    }
}

/* ===== Large Desktop ===== */
@media (min-width: 1400px) {
    .container {
        max-width: 1300px;
    }
}

/* ===== Print Styles ===== */
@media print {
    .navbar, .contact, .footer {
        display: none;
    }
}

⚠️
أخطاء شائعة لازم تتجنبها

🚨 أخطاء في HTML

1. نسيان alt في الصور.

2. نسيان label في الـ Forms.

3. استخدام <div> بدلاً من Semantic elements.

4. أكتر من <h1> في الصفحة.

5. نسيان lang و dir في <html>.

🚨 أخطاء في CSS

1. استخدام px لكل شيء بدلاً من rem.

2. نسيان box-sizing: border-box.

3. استخدام !important كتير.

4. عدم استخدام CSS Variables.

5. نسيان transition مع hover effects.

6. صور بـ width ثابت (مش max-width: 100%).

🚨 أخطاء في Responsive

1. نسيان viewport meta tag.

2. عدم اختبار على موبايل حقيقي.

3. استخدام max-width بدلاً من min-width (Desktop-first).

4. أزرار صغيرة جداً على الموبايل (أقل من 44px).

5. نصوص صغيرة جداً (أقل من 16px).

💎
نصائح احترافية

💎 نصائح من المحترفين

1. ابدأ صغير: اعمل كل section لوحده، وبعدهم اجمعهم.

2. Mobile-first: دايماً ابدأ من الموبايل وبعدين وسّع.

3. استخدم Variables: هيوفرلك وقت كتير في التعديل.

4. Comments: اكتب comments في CSS عشان ترجع تفهم الكود.

5. Git من البداية: اعمل commit بعد كل section.

6. اختبر كتير: افتح DevTools (F12) وجرب أجهزة مختلفة.

7. لا تستعجل: خد وقتك في كل خطوة — الجودة أهم من السرعة.

8. اسأل نفسك: "هل الكود ده نظيف؟ هل حد تاني يقدر يفهمه؟"
